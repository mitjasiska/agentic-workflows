# Reuse the smoke task and separate external fixture cleanup

The minimal live smoke test reuses one manually prepared Linear task and keeps its private GitHub test repository. After a successful authorized run, the operator initially records the result, closes the test PR without merging it, invokes ordinary AW cleanup while the remote branch still preserves committed work, deletes the exact remote test branch, and resets the same Linear task to its configured ready state, initially intended to be To Do. A future runner may automate this sequence after its authorization is specified. Closed PR and Linear history remain; this accepts accumulated test history in exchange for avoiding repeated repository or task provisioning.

AW cleanup retains its existing local scope under [ADR 0030](0030-make-abandonment-resumable-and-support-forced-cleanup.md): owned execution resources, worktree, exact local branch, and Workflow-owned state. The operator, and later a runner, handle external GitHub and Linear fixture teardown using the run's exact identities, and do not report the fixture ready or reset Linear before preceding cleanup is confirmed. Cleanup failure is reported distinctly; it does not silently escalate to forced AW cleanup, replace the repository, or discard unrelated state.

Failed smoke runs retain their existing Workflow, worktree, branches, any created PR, and current Linear state until explicit operator cleanup. This preserves the evidence needed for diagnosis rather than erasing the failing state. A runner failure does not prove external execution stopped, and an unresolved retained fixture is not available for another smoke run. Detailed timeout and partial-cleanup recovery remain open in the [E2E test-kit architecture](../e2e-test-kit.md).
