# Review and adopt unmanaged local commits

AW-managed agents do not create commits, but humans and independently opened agents may use Git in a retained worktree. Review evidence binds the exact comparison baseline and complete Reviewed Tree, not a commit SHA, so committing identical reviewed content does not make its review stale. When Unmanaged Work changes content, AW may perform a fresh independent review of the resulting tree. A later `awctl pr` adopts the one safe local direct-child commit unchanged only when its tree, parent, branch, unpublished state, and complete message match the frozen PR Intent. When every safety condition except the message matches, the same command may replace that one unpushed commit with an AW-authored commit using the identical tree and parent, atomically update the still-expected branch without disturbing the index or worktree, and record the original SHA and provenance gap. A pushed commit, descendant, race, ancestry mismatch, or tree mismatch is refused rather than rewritten. This retains deterministic evidence and truthful public metadata without requiring the user to amend an otherwise safe local commit manually.
