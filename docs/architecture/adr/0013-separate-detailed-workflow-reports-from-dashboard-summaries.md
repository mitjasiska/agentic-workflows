# Separate detailed workflow reports from dashboard summaries

AW stores detailed structured pass reports and composes them with deterministic history into a portable Workflow Report intended for External Orchestrators such as planning agents or chats. It does not retain raw agent transcripts or every tool call, and v1 does not embed the complete code diff in the report. It does include a compact changed-file list derived deterministically from the exact Review Target. Optional diff export is deferred until usage demonstrates a need. The dashboard leads with a numbered workflow timeline and concise operational facts; each Implementer or Reviewer step expands to its detailed report. At any time, users may copy one step, selected steps, or the complete report as query projections over the same durable records. This gives External Orchestrators enough context without forcing human users to read long agent prose or creating the cost, privacy exposure, and complexity of full-session recording.
