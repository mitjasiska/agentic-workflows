# Rely on a private network for dashboard HTTP in single-operator v1

v1 is a single-trusted-operator system and does not implement user accounts, login, authentication, authorization, teams, or RBAC. Its React dashboard and control-plane HTTP API rely on a trusted network perimeter such as loopback or a private Tailscale-style overlay and are not safe for direct public exposure. The HTTP listener binds to loopback by default; an operator may explicitly configure a private-network address and restart the service without migrating the database. This network decision does not apply to `awctl`, which uses only the platform-local Local Control Interface and is restricted to the operating-system account running the control plane. Audit records may identify whether an action originated from the CLI, dashboard, reconciliation, or the system, but do not claim a human identity. Named users, permissions, and actor-attributed audit are deferred to the v3 company-oriented direction; HTTP middleware and database migrations can add them later without changing workflow identities or historical pass data. These seams preserve an upgrade path without a dormant v1 identity subsystem.
