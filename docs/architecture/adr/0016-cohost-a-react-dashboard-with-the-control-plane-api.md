# Co-host a React dashboard with the control-plane API

v1 uses React with TypeScript for its sophisticated dashboard and ASP.NET Core for the control plane. The production frontend build is served as static assets by the same ASP.NET Core service that exposes the control-plane HTTP API, producing one deployable application with one network/perimeter and installation boundary. React is the supported v1 HTTP client; this interface is not `awctl` transport or a promised stable third-party integration contract. React never accesses SQLite, Herdr, or workflow application services directly. It invokes the same application commands and queries that `awctl` reaches separately through the Local Control Interface. Development tooling may run the frontend separately without changing the production architecture or creating a second workflow implementation. Initial E2E may build its two minimal read-only views under the settled information requirements and reversible UI latitude; focused UI/UX design precedes the broader post-milestone dashboard expansion rather than the entire implementation.
