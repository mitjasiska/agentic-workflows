# Derive publication metadata from reviewed results

Linear-backed submission requires exactly one Primary Publication Category—`Feature`, `Bug`, `Chore`, `Docs`, or `Refactor`—to choose the deterministic `feat`, `fix`, `chore`, `docs`, or `refactor` prefix; orthogonal labels such as `Research` may coexist but do not affect the type. A clean Reviewer supplies public-safe summary, description, and validation fields from the exact reviewed result rather than copying the mutable Task title, and AW deterministically freezes `<type>: <summary> (<TASK-ID>)` as both commit subject and PR title, adds a `Task-Review: <pass-id>` commit trailer, and constructs the sectioned PR body with the canonical Linear link and closing reference. Missing or ambiguous classification and missing, invalid, or stale reviewed metadata stop ordinary submission instead of guessing.

This complete commit message is also required when Unmanaged Work has already created the otherwise-safe local direct-child commit. AW adopts that commit unchanged only when its message matches the frozen metadata. When only the message differs and the commit remains unpushed with no descendant, `awctl pr` replaces it with an AW-authored commit using the identical tree and parent and records the original SHA in the Workflow Audit Trail. This prevents arbitrary or private local commit text from becoming public and preserves the review marker without changing reviewed file content.

An explicit forced submission without current Reviewed Publication Metadata uses the exact generic subject and PR title `<type>: complete requested change (<TASK-ID>)`, the commit trailer `Task-Review: bypassed-by-force`, and a sectioned PR body whose Validation section discloses that independent review was bypassed with `awctl pr --force`. AW freezes this metadata in the PR Intent and does not copy the mutable Task title, publish unreviewed agent prose, or require interactive composition. This preserves the one-command Force Override while making the missing independent review permanently visible in Git and forge history. Optional public-safe overrides are deferred.
