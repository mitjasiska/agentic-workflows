# Model human input as an orthogonal attention condition

Conditions that require a human policy choice or manual/external action do not become additional Workflow phases. AW retains the current Workflow Phase and exposes zero or more typed Attention Requirements derived from current facts. Users never mark them resolved individually. Each ordinary recovery action revalidates all available facts and automatically clears every current alert that no longer applies, while the Workflow Audit Trail retains its creation and clearance. A `Failed`, `Interrupted`, or temporarily unreachable Operation already has its own status, diagnostic, and Recovery Plan and is not automatically duplicated as an Attention Requirement. `AttentionRequired` is the derived gate while any requirement currently applies. It blocks automatic start of the next gated action without automatically interrupting a running pass, changing an Operation result, or declaring the Workflow failed.

The Initial E2E reason set is deliberately limited to `TaskChangeDecision`, `PassContinuationDecision`, `PassBudgetContinuation`, `LinearCancellationDecision`, and `RepositoryReconciliation`. `PassContinuationDecision` is available only when a normally completed pass identifies a concrete material decision or external prerequisite that cannot be resolved safely within the existing Task scope; its Result Envelope must explain why and propose a resolution. It is not a generic agent escape hatch for routine findings, unrelated failures, or investigable uncertainty. Session loss, result-contract failure, review staleness, provider failure, and temporary unreachability stay in their existing Operation, evidence, eligibility, and Recovery Plan concepts; another attention reason requires a concrete scenario those concepts cannot represent clearly. There is no `mark-resolved` command or requirement-by-requirement repair flow. One action may clear several alerts after revalidation, and `awctl cleanup --force` remains the direct escape hatch. Keeping phase, Operation Status, execution observation, and attention separate avoids the prototype's combinatorial blocked-state model while retaining precise diagnostics and low-friction recovery.
