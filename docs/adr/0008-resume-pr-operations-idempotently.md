# Resume the PR action chain idempotently

V1 exposes one `awctl pr` command that composes internal commit, push, and pull- or merge-request actions. Preflight freezes one durable PR Intent before mutation, and the resulting action chain is resumable and idempotent: retry reconciles actual Git and forge state, reuses already-completed correlated effects, and continues remaining actions rather than rolling back, adopting later worktree content, or creating duplicate commits or requests. Remote divergence stops only the unsafe submission operation and is never overwritten, force-pushed, or automatically pulled, merged, or rebased, including under a Force Override; the user reconciles it manually and reruns `awctl pr` without separate workflow-state repair or loss of access to the retained worktree.
