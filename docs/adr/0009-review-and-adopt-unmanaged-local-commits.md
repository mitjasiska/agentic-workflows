# Review and adopt unmanaged local commits

AW-managed agents do not create commits, but humans and independently opened agents may use Git in a retained worktree. Review evidence binds the exact comparison baseline and complete Reviewed Tree, not a commit SHA, so committing identical reviewed content does not make its review stale. When Unmanaged Work changes content, AW may perform a fresh independent review of the resulting tree. A later `awctl pr` may adopt a clean local commit whose tree matches the review, then push and create or update the request after separate ancestry and target checks, while preserving the provenance gap instead of claiming AW created the commit. This retains deterministic evidence and submission safety without constraining recoverable human intervention.
