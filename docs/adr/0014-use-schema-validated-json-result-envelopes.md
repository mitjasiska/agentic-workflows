# Use schema-validated JSON result envelopes

Each Managed Agent Pass writes exactly one UTF-8 JSON Result Envelope to an AW-authorized location outside the managed worktree. All roles use one versioned universal schema with a role discriminator and strictly required role-specific payloads, avoiding both duplicated top-level contracts and a flat collection of unrelated optional fields. The envelope is correlated to the expected pass and contains a constrained outcome, typed evidence, and detailed human-readable narrative fields. Deterministic workflow code validates it before routing, so malformed, missing, ambiguous, or inconsistent agent output cannot authorize success. When normal turn completion is positively confirmed but the envelope is missing or invalid, AW records a recoverable Failed Operation with a specific contract diagnostic, preserving the worktree, session, and evidence. The complete validated envelope is stored immutably in SQLite as durable pass evidence, together with a typed relational projection of fields needed for routing and queries. Both are created from the same validated object in one transaction and are not independently editable; the temporary JSON file is transport only. This preserves the prototype's proven JSON delivery mechanism while allowing the successor to refine its contract rather than treating free-form Markdown as workflow control data.
