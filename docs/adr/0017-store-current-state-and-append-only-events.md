# Store current state and append-only events

SQLite stores explicit current workflow state alongside the append-only Workflow Audit Trail. Each successful application command updates the affected current-state records and appends its historical events atomically in one transaction. For agent completion, that transaction also stores the complete validated JSON Result Envelope, its typed relational projection, and any pending intent for the next external action. The envelope and projection are derived from one validated object and cannot be edited independently. Dashboard and workflow decisions query current state directly, while events explain how that state was reached. A workflow-history projection turns those records into stably ordered, meaningful steps with concise outcomes and links to detailed reports; later conclusions never erase earlier steps while the Workflow is retained. Explicit cleanup may delete the selected Workflow's current state and complete event history. AW does not reconstruct ordinary current state by replaying the complete event history. This provides efficient centralized queries and observability without the implementation and migration complexity of full event sourcing or a permanent project registry.
