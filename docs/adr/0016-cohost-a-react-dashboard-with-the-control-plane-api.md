# Co-host a React dashboard with the control-plane API

v1 uses React with TypeScript for its sophisticated dashboard and ASP.NET Core for the control plane. The production frontend build is served as static assets by the same ASP.NET Core service that exposes the HTTP API, producing one deployable application with a simple authentication and installation boundary. React remains an API client and never accesses SQLite, Herdr, or workflow application services directly. Development tooling may run the frontend separately without changing the production architecture or creating a second workflow implementation. Detailed UI/UX design is a focused phase after core architecture refinement and before implementation, rather than a concern that drives the present control-plane design.
