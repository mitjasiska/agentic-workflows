# Preserve managed work in an append-only audit trail

Every Managed Agent Pass and deterministic AW action contributes its available inputs, events, detailed structured reports, evidence, measurements, decisions, and overrides to a durable Workflow Audit Trail that powers both the dashboard and `awctl`. Later activity may supersede earlier conclusions but does not rewrite them. AW does not retain every message, terminal interaction, or tool call. Unmanaged Work remains permitted in V1 and is represented only by the observable state change and provenance gap detected at a deterministic checkpoint; AW does not invent a missing agent history. Organization-level enforcement that confines developers to managed workflows is deferred as a separate governance capability. This prioritizes development speed and honest observability for experienced programmers without claiming visibility AW does not possess.
