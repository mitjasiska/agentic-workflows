# Budget managed agent passes

AW limits unattended implementation/review looping with a configurable Managed Agent Pass Budget that counts both Implementation Passes and Review Passes. Its default is six passes, permitting an initial implementation/review pair and two repair/review pairs. A finite budget is enforced only at pass boundaries: the active pass finishes and its result is recorded, then AW pauses before starting another pass when none remain. This requires human interaction and explicit continuation; it is not a failed workflow. Plain `awctl continue` grants another configured batch, six by default. `awctl continue --max-passes N` grants a different finite batch, and `awctl continue --max-passes unlimited` disables the pass-count pause for that invocation without changing saved configuration. v1 does not infer Unlimited from missing configuration or attempt to derive pass control from provider usage windows. Time-based limits and automatic recovery after provider exhaustion are deferred until their semantics can be evaluated from real behavior.
