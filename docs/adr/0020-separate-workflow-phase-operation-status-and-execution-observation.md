# Separate workflow phase, operation status, and execution observation

AW models Workflow Phase, Operation Status, and Execution Observation separately. A Workflow can remain in the Review phase while its concrete Review Operation is pending, running, completed, failed, or interrupted. The Operation's status is also distinct from AW's timestamped last verified Herdr observation: recording start intent does not prove execution started, and an unreachable Herdr target does not prove execution stopped. AW retains the last confirmed observation and marks current reachability unavailable. It records Interrupted only after positive reconciliation evidence establishes that the original execution disappeared without a valid result. This separation avoids a combinatorial workflow-state enum and prevents missing external information from being converted into false certainty.
