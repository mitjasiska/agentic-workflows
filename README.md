# Agentic Workflows

Reusable tooling, skills, and automation for efficient agentic software development workflows.

The goal is to reduce repetitive development mechanics and make working with coding agents across multiple projects fast, consistent, and predictable.

Current focus:

- Linear → Git → Herdr → coding-agent workflow
- reusable agent skills and prompts
- task/worktree lifecycle automation
- human review and control at important checkpoints

This repository is intentionally practical and will evolve from real development workflows rather than a predefined framework.
